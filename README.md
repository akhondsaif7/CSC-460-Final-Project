CSC460 Project 4 Terminal App
=============================

Compile:

```sh
javac *.java
```

Alternatively, you can use the provided makefile
```sh
make
```

Add the Oracle JDBC driver on the classpath:

```sh
export CLASSPATH=/usr/lib/oracle/19.8/client64/lib/ojdbc8.jar:${CLASSPATH}
```
Run

```
java Prog4
```
